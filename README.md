# Pacific Sweep

A vertical fighter you can play in the browser. GitHub's code page does not run the game. Open this link instead:

https://cdn.jsdelivr.net/gh/Holqang/pacific-sweep@main/index.html

The link can take a minute to start working after the first upload.

## How to play

1. Press **Take off** (or the Enter key).
2. Move with the arrow keys or WASD. Left goes left. Right goes right.
3. Space shoots. Shift rolls through enemy fire.
4. On a phone, use the Up, Down, Left, Right, Fire, and Roll buttons.

Every fifth wave is a bomber. Your best score stays in this browser.
